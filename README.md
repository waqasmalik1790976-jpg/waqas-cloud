# Payment Slips

Editable payment slips webapp (Bank slip, Party slip, Petrol slip) with Duplicate, Slip Copy and a New Slip Generator.

## GitHub Pages par chalane ka tareeqa
1. GitHub par new repository banayein (e.g. `payment-slips`).
2. Is zip ko extract karke andar ki files (`index.html`, `.nojekyll`, `README.md`) repository mein upload karein.
3. Repository > Settings > Pages > Source: `Deploy from a branch`, Branch: `main` / `(root)` > Save.
4. 1-2 minute baad aapka link ban jayega: `https://USERNAME.github.io/payment-slips/`

Data browser ke localStorage mein save hota hai (har device/browser ka apna data).
